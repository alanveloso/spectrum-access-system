# Domain glossary

Concise expansions used in this codebase and WInnForum / CBRS materials.

| Acronym | Meaning |
|---------|---------|
| **SAS** | Spectrum Access System |
| **CBSD** | Citizens Broadband Radio Service Device |
| **FAD** | Full Activity Dump (SAS↔SAS synchronization artifact) |
| **CPAS** | Coordinated Periodic Activities among SASs |
| **IAP** | Iterative Allocation Process (incumbent protection power allocation) |
| **DPA** | Dynamic Protection Area |
| **ESC** | Environmental Sensing Capability |
| **PAL** | Priority Access License |
| **PPA** | PAL Protection Area |
| **FSS** | Fixed Satellite Service (earth station protection context) |
| **GWBL** | Grandfathered Wireless Broadband Licensee |
| **BPR** | Boundary Protection / related protection reporting context in WInnForum campaigns |
| **CPI** | Certified Professional Installer |
| **SAS-SAS** | Inter-SAS interface (including FAD exchange) |
| **EIRP** | Equivalent Isotropically Radiated Power |
| **HAAT** | Height Above Average Terrain |
| **EXZ** | Exclusion Zone |
| **ITM** | Irregular Terrain Model (propagation) |
| **eLSA** | evolved Licensed Shared Access (ETSI) |
| **TVWS** | Television White Space |

Stable regulatory requirement identifiers such as `ELSA-001`, `BR-SLP-3700-001`, and `WINNF.FT.S.*` are preserved as normative traceability labels.
